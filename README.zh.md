# Awesome Maker [![Awesome](https://awesome.re/badge-flat2.svg)](https://awesome.re)

一个精选的 [创客](https://en.wikipedia.org/wiki/Maker_culture) 资源列表。

## 社区

- [Instructables](https://www.instructables.com/) - 涵盖几乎所有主题的众多教程
- [hackster](https://www.hackster.io/projects) - 社区驱动的项目目录
- [hackaday](https://hackaday.io/lists) - 社区驱动的项目目录
- [Electromaker](https://www.electromaker.io/) - 社区驱动的项目目录和博客文章
- [OSHWHub](https://oshwhub.com/) - 开源硬件社区和项目分享平台
- [DF创客社区](https://www.dfrobot.com.cn/) - 中文创客社区，提供教程和项目分享

## 知识

- [MagPI](https://www.raspberrypi.org/magpi-issues/) - 所有 MagPI 期刊的免费（官方）PDF 存档
- [Hackspace](https://hackspace.raspberrypi.org/issues) - 所有 Hackspace 期刊的免费（官方）PDF 存档
- [DIYODE](https://diyodemag.com/issues) - DIYODE 期刊存档（付费）
- [硬禾学堂](https://class.eetree.cn/) - 中国电子和嵌入式系统学习平台
- [达尔闻说](https://www.darwinlearns.com/) - 中国电子学习平台，提供教程和课程
- [freeCodeCamp](https://www.freecodecamp.org/) - 免费的在线编程训练营，提供数千个编程教程

## 购买与销售

- [Kickstarter](https://www.kickstarter.com/) - 创意项目的众筹平台
- [Tindie](https://www.tindie.com/) - 创客销售其项目的市场平台
- [Crowdsupply](https://www.crowdsupply.com/) - 创客界的 Kickstarter
- [GroupGets](https://groupgets.com/) - 批量订单的众筹活动
- [Adafruit](https://www.adafruit.com/) - 电子元件、工具和学习资源
- [Seeed Studio](https://www.seeedstudio.com/) - 开源硬件促进公司，提供开发板和模块

## 电子

### EDA & CAD 软件

- [FreeCAD](https://www.freecadweb.org/) - 一个自由开源的多平台 3D 参数化建模器
- [Fritzing](https://fritzing.org/) - 一个自由开源的项目，旨在开发业余或爱好者 CAD 软件，用于电子硬件设计
- [KiCad](https://kicad.org/) - 一个自由开源的跨平台电子设计自动化套件
- [EasyEDA](https://easyeda.com/) / [立创EDA](https://lceda.cn/) - 免费易用的在线 PCB 设计工具，集成元件库和制造服务

## 3D 打印

### 模型

- [Thingiverse](https://www.thingiverse.com/) - 最大的 3D 可打印模型网站
- [MyMiniFactory](https://www.myminifactory.com/) - 一个更新、更现代的 3D 模型页面
- [Printables (formerly PrusaPrinters)](https://www.printables.com/) - Josef Prusa 创建的新 3D 模型注册表，针对 Prusa 3D 打印机进行了优化
- [MakerWorld](https://makerworld.com/) - 3D 打印模型分享平台，集成切片和打印服务
- [yeggi](https://www.yeggi.com/) - 3D 可打印模型的元搜索引擎

### 切片与控制软件

- [OctoPrint](https://github.com/foosel/OctoPrint) - 3D 打印的 Web 界面
- [Ultimaker Cura](https://github.com/Ultimaker/Cura) - 一个自由开源的切片应用程序，用于准备 3D 模型进行 3D 打印
- [PrusaSlicer](https://www.prusa3d.com/page/prusaslicer_424/) - Prusa 创建的自由开源切片应用程序，用于准备 3D 模型进行 3D 打印，完全兼容其他制造商的打印机

### 实用软件

- [Meshroom](https://github.com/alicevision/meshroom) - 开源 3D 重建软件，用于从图片创建 3D 模型
- [TinkerCAD](https://www.tinkercad.com/) - 浏览器中的简单易用 3D 建模软件
- [OpenSCAD](https://www.openscad.org/) - 自由开源的纯脚本应用程序，用于创建实体 3D CAD 对象
- [Terrain2STL](http://jthatch.com/Terrain2STL/) - 将真实世界地图数据转换为可 3D 打印的 STL 文件

### 故障排除

- [Matterhackers 故障排除指南](https://www.matterhackers.com/articles/3d-printer-troubleshooting-guide) - 通用 3D 打印故障排除指南
- [Simplify3D 故障排除指南](https://www.simplify3d.com/support/print-quality-troubleshooting/) - 更侧重于 Simplify3D 的故障排除指南
- [Prusa3D 故障排除指南](https://help.prusa3d.com/category/print-quality-troubleshooting_225) - 深入的故障排除帮助文章集合。专注于 Prusa 打印机，但包含适用于所有打印机的通用知识和技巧
